Foundation

Iconography

Line icons on a 24-unit grid with a 2px round stroke in currentColor, drawn inline as SVG. Every icon in the mocks is shown here.

WCAG 2.2 AA
  • Overview
  • Sizes
  • The set
  • Usage
  • Accessibility

Overview

Icons are inline <svg class="icon" viewBox="0 0 24 24" aria-hidden="true">; .icon sets no fill, a 2px round stroke and currentColor. They are bundled in the markup, never loaded from a CDN. The set follows the Lucide style used by the Magic Patterns designs.

Sizes

16px (.icon--sm), 20px (default), 24px (.icon--lg). In buttons icons are 1.25em.

Usage

  • An icon means one thing everywhere: the octagon is only the emergency stop; the file is only Evidence.
  • Icons sit beside words; icon-only buttons have an aria-label.
  • Decorative icons are aria-hidden="true".
  • Status icons are always paired with a status word.

Accessibility

Icons that carry meaning need 3:1 against their background; they inherit text colour, which already passes 4.5:1.

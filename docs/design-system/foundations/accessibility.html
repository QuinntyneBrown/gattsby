Foundation

Accessibility

WCAG 2.2 AA throughout (NFR-011), and more where the machine makes it matter: 48px targets, a 20px prompt, and a 7:1 emergency-stop label.

WCAG 2.2 AA
  • Overview
  • Perceivable
  • Operable
  • Understandable
  • Robust
  • Testing
  • Tokens

Overview

Every component page documents its role, keyboard map, focus, labelling, contrast in both themes, motion and touch. The checker scripts enforce the mechanical parts; the rest is tested by hand.

Perceivable

RuleSCIn Gattsby
Text contrast1.4.34.5:1 for all text in both themes; pairs in contrast-pairs.json.
Non-text contrast1.4.113:1 for control edges, the focus ring, verdict marks, the switch track; invalid edges use --color-border-danger.
Use of colour1.4.1Confidence is a word and a shape; verdicts a word and a mark; links are underlined.
Reflow1.4.10No horizontal scroll from 320px; type in rem.
Text spacing1.4.12Layouts survive 1.5 line height and 0.12em letter spacing.
Orientation, motion1.3.4, 2.3.3No lock; transitions zeroed under reduced motion.

Operable

RuleSCIn Gattsby
Keyboard2.1.1Everything works with Tab, Enter, Space and Esc; sheets trap focus and release on Esc.
Focus visible2.4.7, 2.4.11One ring: 2px --color-focus-ring, 2px offset; the sticky app bar never hides focus (scroll-padding-top).
Target size2.5.848 × 48px for every target (stricter than 24px), 8px apart.
Skip2.4.1Skip link on every page.
Timing2.2.1Toasts last 8 s and pause on hover and focus; errors persist; approvals never time out.
Pointer cancellation2.5.2Actions fire on click; the emergency stop on click too, never on press-and-hold.

Understandable

RuleSCIn Gattsby
Labels3.3.2Visible labels; “(optional)” marks the optional ones.
Errors3.3.1, 3.3.3Error text says how to fix it; a summary links each error; aria-invalid + aria-describedby.
Error prevention3.3.4Every write or control call needs its own approval; deletes are confirmed; delete all data needs typing.
Consistent3.2.3The stop is the same shape and place on every connected screen and sheet.

Robust

  • Native elements first: button, a, input, dialog, dl, table.
  • Status messages in live regions: the prompt dock is aria-live="polite"; toasts are status or alert.
  • Model output, device names and every byte-derived string are rendered as text, never HTML (AGENTS.md, NFR-013).

Testing

  • check_contrast.py for every pair in both themes.
  • check_design_system.py and check_mocks.py for labels, names, alt text, landmarks and links.
  • By hand: Tab through each component page; a screen reader through the approval sheet, the feed and the evidence log; 200% and 400% zoom; reduced motion and forced colours.

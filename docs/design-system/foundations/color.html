Foundation

Color

Ink, paper and signal. Paper is the light theme, ink the dark one; signal orange marks only what is live. Every colour a component uses is a role, and every role pairing is checked for contrast in both themes.

Overview

Three brand colours from the Magic Patterns Gattsby Brand prototype: ink #15171B, paper #F3F1EA and signal #FF5A1F. Status colours (green, amber, red) are muted to sit beside them. Primary actions are ink on paper and paper on ink, so the most important action is always the highest-contrast object on screen. Signal is reserved for what is live: the current stage, the Live badge, the device dot in the mark and open missing-tool requests.

Components never read a --palette-* token; they read roles (--color-*). A theme changes roles only.

Both themes

Dark is not inverted light: surfaces get lighter as they rise (canvas ink-900 < surface ink-850 < raised ink-800), accents flip to paper with an ink label, status backgrounds are deep tints with light text.

Usage

  • Primary actions: --color-accent. One per view.
  • Signal only for live things; never for a button, an error or decoration.
  • Danger red only for the emergency stop, destructive confirmations and errors. Invalid edges use --color-border-danger, which reads on ink.
  • Decorative borders (--color-border-default) may be faint; control edges use --color-border-strong (3:1).
  • Never put colour on its own: confidence is a word and a shape; verdicts are a word and a mark.
  • To add a theme, override the roles in a [data-theme="name"] block: see Theming.

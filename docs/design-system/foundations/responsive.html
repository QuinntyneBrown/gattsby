Foundation

Responsive

Mobile first and one-handed: the emergency stop stays pinned at the top, the primary action at the bottom, and from 992px the prompt moves beside the feed.

WCAG 2.2 AA
  • Overview
  • Rules
  • By component
  • Testing

Overview

The person is often holding a phone in one hand beside a moving machine. Base styles target 360px; breakpoints add room (NFR-009, NFR-010).

Rules

  • Under 768px: one column; the app bar (with the stop) is sticky; the prompt dock, action bar or readiness actions are pinned at the bottom.
  • Touch targets 48 × 48px with 8px between them, everywhere.
  • Text never truncates in buttons; device names and meta lines may.
  • Horizontal scrolling only inside chip rows and the live strip, never the page.
  • 100dvh for full-height shells so mobile browser chrome does not clip the dock.

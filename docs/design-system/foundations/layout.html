Foundation

Layout

Mobile first at 360px, with the breakpoints NFR-010 names: 576, 768, 992 and 1200px. Columns, gutters and margins are tokens that change at each step.

Overview

Gattsby is used one-handed on a phone beside a machine, and on a laptop on the same store floor. Layouts start at 360px and add room. No screen scrolls sideways at any width from 320px (NFR-010 AC1).

Breakpoints

TokenWidthColumnsGutterMarginWhat changes
(base)0–575px416px20pxOne column; emergency stop pinned at the top, primary action pinned at the bottom.
--layout-breakpoint-sm576px416px20pxSheets centre; toasts move to the corner; action bars share a row.
--layout-breakpoint-md768px824px32pxPause returns to the app bar; Stop label in full; readiness actions unpin.
--layout-breakpoint-lg992px1232px32pxPrompt and live readings beside the feed; profile photos beside data.
--layout-breakpoint-xl1200px1232pxautoContent stays at its max width and centres.

Queries use min-width in rem (36rem, 48rem, 62rem, 75rem). Custom properties cannot be used inside @media, so the values are repeated there by convention.

Usage

  • Read --layout-* tokens instead of writing new media queries where possible.
  • Keep DOM order equal to visual order; grid placement never reorders content.
  • Pinned bars (dock, action bar, readiness actions) leave room for env(safe-area-inset-bottom).

Empty and error state

Empty and error states fill a page that has nothing to show: no saved devices yet, no results for a filter, or storage that would not open. Each says why and offers one way forward.

WCAG 2.2 AAStatus: stable

Overview

.empty: a 56px icon circle, a title, one or two sentences and up to two actions. .empty--error tints the icon danger; .empty--compact is for a section rather than a page. The not-found page uses the same component.

Anatomy

  1. Icon56px circle.
  2. TitleWhat is (not) here.
  3. TextWhy, and what the page will hold.
  4. ActionsOne primary, one secondary.

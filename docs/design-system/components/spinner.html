Spinner

A spinner says something is happening and how long is unknown: a step running, a reconnect, a check in progress.

WCAG 2.2 AAStatus: stable

Overview

Use a spinner inline beside text that says what is happening. Use a skeleton while a page’s content loads and a progress bar when the amount is known.

Anatomy

  1. Ring2px border, accent arc; turns every --duration-spin.

Variants

States

One state: turning. It never shows disabled or paused.

Both themes

WorkingLoading
WorkingLoading

Responsive behaviour

  • Same at every width.

Theming

The arc is --color-accent on a --color-border-default ring; in a running tool call the arc is --color-signal; in a warning banner it follows the warning icon colour.

Accessibility

Role and pattern

role="status" with visually hidden text naming what is loading.

Keyboard

KeyAction
—Not focusable; content is read in order.

Focus

Not focusable.

Labelling

“Reconnecting”, “Checking”, never “Loading…” on its own when the task has a name.

Contrast

Live ratios, light then dark.

Arc

Motion

Keeps turning under reduced motion: it is a status, not decoration.

Touch

Not a target.

Content

  • Pair with text saying what and, for retries, which attempt: “Reconnecting, attempt 2 of 3”.

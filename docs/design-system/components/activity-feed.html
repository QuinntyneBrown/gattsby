Activity feed

The activity feed is the conversation: the agent’s messages with why, the person’s answers, stage dividers, tool calls and hypothesis changes, newest at the bottom.

Overview

The feed (.feed) reads like a chat because the person is following prompts. It opens at the latest entry (column-reverse scrolling). Entries:

  • Agent message: the mark as avatar, the text, and Why: in muted text (FR-050).
  • Person’s message: an inverse bubble on the right.
  • Stage divider: the playbook stage name with a rule.
  • Tool call, indented under the message that asked for it.
  • Hypothesis change: old → new confidence and the badge.

Anatomy

  1. AvatarThe mark in a 24px circle.
  2. Message16px, relaxed line height.
  3. WhyMuted, “Why: …”.

Sizes

One size; the feed caps at 42rem.

States

Entries are static. The feed has three states: running (a running tool call at the end), waiting (the dock holds a prompt), loading (skeleton bubbles; see Skeleton).

Responsive behaviour

  • Full width under 992px with 16px (24px from 768px) padding; from 992px it takes the left column beside the prompt and panel.

Theming

Agent text on the canvas; the person’s bubble uses --color-bg-inverse; hypothesis changes sit on --color-bg-subtle.

Accessibility

Role and pattern

An ordered list; each message starts with visually hidden “Agent:” or “You:”. Model output is rendered as text, never HTML (AGENTS.md).

Keyboard

KeyAction
TabMoves through links inside entries (Evidence).
ScrollThe feed is a scroll region with tabindex="0" and a label.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

The feed region is labelled “Activity”. New entries are not announced one by one; the dock’s live region announces the prompt.

Contrast

Live ratios, light then dark.

Content

  • The agent speaks in first person, short sentences, and always gives a why before a step.
  • The person’s entries record what they tapped or typed, verbatim.

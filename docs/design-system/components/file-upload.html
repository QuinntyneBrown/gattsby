File upload

File upload brings a file in: an exported profile or investigation record to import, or a photo of the model plate. The native file input is always the control.

WCAG 2.2 AAStatus: stable

Overview

  • Drop zone (.dropzone): import. A dashed area with what is accepted and a Choose a file button.
  • File chip (.file-chip): the chosen file’s name and size, mono.
  • Photo grid (.photo-grid, .photo-add): photos attached to an investigation, with an add tile. Photos stay local (NFR-017).

Anatomy

  1. Icon24px upload.
  2. What is acceptedPlain sentence with the extension.
  3. ButtonOpens the native picker; the real control.

Responsive behaviour

  • Drag and drop is an enhancement for desktops; phones use the button.
  • The photo grid stays three across at every width.

Theming

The dashed edge is --color-border-strong; file chips sit on --color-bg-surface-sunken.

Accessibility

Role and pattern

A visually hidden <input type="file" accept=".json"> triggered by the button, or the input itself styled as the button. The add-photo tile is a button.

Keyboard

KeyAction
TabReaches Choose a file / Add photo.
Enter, SpaceOpens the picker.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

The button names the action; the result (chosen file, error) is announced through the sheet’s live region.

Contrast

Live ratios, light then dark.

Motion

None.

Touch

Button and tiles are at least 48px; no drag required (2.5.7).

Content

  • Say what is accepted and where it came from: “exported by Gattsby (.json)”.
  • Errors name the problem in the file: “Not a Gattsby file: the profile format is missing.”

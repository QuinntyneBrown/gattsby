Text field

Text fields take what only the person can type: a location, a note, a correction to a model plate, a search. Each has a visible label, optional help and an error that says how to fix it.

WCAG 2.2 AAStatus: stableIncludes textarea and search

Overview

The field wrapper (.field) stacks label, control, help and error, 4px apart. The control is .input (one line), .textarea (a note) or an input inside .search-field (saved devices, evidence log). Gattsby asks for very little typing: the person is standing beside a machine. Prefer quick replies, chips and buttons, and keep fields for what cannot be picked.

Anatomy

  1. Label--text-label, always visible; “(optional)” in muted text when it is.
  2. Control48px tall, --color-border-strong edge, --radius-md, 16px text so phones do not zoom.
  3. Help or error--text-body-sm; the error is danger text with a warning sign, linked by aria-describedby.

Variants

Text input and textarea.
HTML
<div class="stack" style="width: 100%; max-width: 24rem;"><label class="field"><span class="field__label">Location <span class="optional">(optional)</span></span><input class="input" type="text"  value="Decathlon, Lille"></label><label class="field"><span class="field__label">Note</span><textarea class="textarea" rows="3"></textarea><span class="field__help">What you saw on the console, or anything the agent should know.</span></label></div>
Search: icon inside, a visually hidden label, the placeholder only as a hint.
HTML
<div class="search-field" style="width: 100%; max-width: 24rem;"><svg class="icon" viewBox="0 0 24 24" aria-hidden="true">…</svg><label class="visually-hidden" for="v-q">Search saved devices</label><input class="input" id="v-q" type="search" placeholder="Search brand, model or protocol"></div>

Sizes

One size: 48px controls with 16px text. Smaller text makes iOS and Android zoom the page on focus.

Responsive behaviour

  • Fields are full width of their column at every size; a sheet caps them at 28rem.
  • The search field sits above the filter chips at every width; it never moves into the app bar.

Theming

Fields read three component tokens, --field-bg, --field-border and --field-border-hover. Invalid swaps --field-border for --color-border-danger, which is red-700 on paper and red-300 on ink so the edge clears 3:1 in both.

Accessibility

Role and pattern

Native <input> and <textarea> wrapped in a <label class="field">, or with <label for>.

Keyboard

KeyAction
TabMoves to the field.
TypingEdits; nothing submits on change.
EnterIn a one-line field inside a form, submits it.

Focus

A 2px ring of --color-focus-ring with no offset, and the edge takes the ring colour. On submit with errors, focus moves to the error summary.

Labelling

Visible label always; placeholder is a hint, never the label. Help and error are linked with aria-describedby; invalid sets aria-invalid="true". Location fields set autocomplete="off": Gattsby never looks up where the person is.

Touch

Content

  • Labels are nouns: Location, Note, Maker. Mark the optional ones, not the required ones.
  • Errors say what to do: “Add a location, a note or a photo before saving.”
  • Help says what happens to the value: “Typed by you. Gattsby never looks up where you are.”

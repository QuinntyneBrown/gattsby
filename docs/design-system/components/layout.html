Layout primitives

The layout primitives place everything else: the app shell, page columns at three widths, stacks and clusters. They read the layout tokens, so a breakpoint changes the token, not the component.

Overview

  • App (.app, .app--fixed): the full-height column; fixed for the investigation, whose feed scrolls inside it.
  • Page (.page): a centred column with the page margin; .page--reading (42rem) for the verdict and feed, .page--narrow (28rem) for the readiness check.
  • Stack (.stack): vertical, 16px gaps (--sm 8px, --lg 32px). Cluster (.cluster): wrapping row, 12px gaps.
  • Grid (.grid): 4, 8 or 12 columns with the layout gutter; .profile-grid puts the device profile’s photos beside its data from 992px.
  • Action bar (.action-bar): the bottom bar pinned under the verdict with its actions.

Anatomy

  1. Margin--layout-margin: 20px, 32px from 768px.
  2. Columns and gutter4 / 8 / 12 columns, --layout-gutter 16 / 24 / 32px.

Responsive behaviour

  • Base (under 576px): 4 columns, 16px gutter, 20px margin.
  • From 768px: 8 columns, 24px gutter, 32px margin.
  • From 992px: 12 columns, 32px gutter; the investigation adds its 22rem side panel.
  • Never a horizontal page scroll at any width from 320px (NFR-010).

Theming

Layout reads no colour. It reads --layout-* and --space-* only.

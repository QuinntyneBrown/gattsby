Data table

Data tables list a profile’s metrics and controls with their decoding rule, rate and status, and a tool call’s rows of findings.

WCAG 2.2 AAStatus: stable

Overview

.data-table: no zebra, rules between rows, caption visually hidden, numbers right-aligned in mono, status badges in the last column. .probe__rows is the compact version inside a tool call.

Anatomy

  1. HeaderCaption-size muted text.
  2. Metric and unitBody text; unit in caption.
  3. RuleMono decoding rule.
  4. NumberRight-aligned mono.
  5. StatusBadge.

Sizes

One density.

States

Static: no row hover or selection. Loading uses skeleton rows; an empty table is replaced by a sentence (“No metrics decoded yet”).

Responsive behaviour

  • Three columns fit at 360px because the rule sits under the metric, not in its own column.
  • Rules wrap anywhere; no horizontal scroll.

Theming

Text and rules only: --color-fg-default, --color-fg-muted, --color-border-default.

Accessibility

Role and pattern

<table> with <caption> and scope on headers.

Keyboard

KeyAction
—Not focusable; content is read in order.

Focus

Not focusable.

Labelling

Caption names the table; the status column has a visually hidden header.

Contrast

Live ratios, light then dark.

Cell
Header, rule, number

Motion

None.

Touch

No targets.

Content

  • Rule format: <uuid> · <where> · <type> · <scale>.
  • Rates in Hz; units in the unit span, not the value.

Menu

The menu is a list of actions inside a sheet: the investigation options and the export choices. Each item has an icon, a title and a line saying what it does.

WCAG 2.2 AAStatus: stable

Overview

Gattsby has no dropdown menus. A set of actions opens as a bottom sheet (a dialog) holding a .sheet-menu, which is easier to hit one-handed than a popup and works the same at every width. Use it for the investigation options (pause, add a note, photo, evidence, stop) and for export.

Anatomy

  1. Icon20px, inherits the item colour.
  2. TitleA verb phrase, --text-label at 16px.
  3. DetailWhat happens, muted.

Variants

Emergency stop

Investigation options

  • Pause
  • Add a note or the location
  • Photo of the model plate or console
  • Evidence
  • Stop and get a verdict now
Investigation options: actions, a divider, then the destructive stop at the end.

Sizes

One size: every item is at least 48px tall.

States

VariantDefaultHoverFocusDanger
Item

Both themes

Responsive behaviour

  • A bottom sheet under 576px, a centred sheet from 576px; the list is identical.

Theming

Items are transparent on the raised surface; hover uses --color-bg-canvas so it reads on both paper and ink. The danger item uses --color-danger-fg.

Accessibility

Role and pattern

A list of links (routes) and buttons (actions) inside a modal dialog. It is not an ARIA menu: items are ordinary tab stops, which works with every screen reader and needs no roving focus.

Keyboard

KeyAction
Tab / Shift+TabMoves between items.
EnterActivates.
EscCloses the sheet and returns focus to the Options button.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind. Opening the sheet focuses its title; closing returns focus to the trigger.

Labelling

The title is the name; the detail is extra text in the same element.

Contrast

Live ratios, light then dark.

Title
Detail
Danger item

Motion

The sheet slides up over --duration-slow; items do not animate.

Touch

Full-width 48px rows.

Content

  • Title: verb phrase. Detail: the consequence in a few words (“Every step, packet and answer · 86 KB”).
  • The destructive item comes last, after a divider.

Live reading

Live readings show what the machine is reporting right now, in 32px mono so they can be read at arm’s length, each marked with how sure Gattsby is of the field.

WCAG 2.2 AAStatus: stableNFR-009

Overview

On phones the readings run in a strip above the prompt (.live-strip), with a pulsing Live badge. From 992px they move to the side panel as a key-value list (see Key-value list). A field not yet labelled shows its raw bytes in muted text (.reading--unknown).

Anatomy

  1. Label and markerCaption; “~” likely, “?” not labelled, “✕” not confirmed, none when confirmed; the word is visually hidden.
  2. Value--text-metric: 32px Geist Mono, tabular.
  3. UnitCaption, muted.

Responsive behaviour

  • Under 992px: a horizontally scrolling strip in the dock, edge to edge.
  • From 992px: the strip hides and the side panel lists the readings.

Theming

Values read --color-fg-default; the Live badge reads --color-fg-signal with a --color-signal dot.

Accessibility

Role and pattern

role="group" aria-label="Live readings". The strip is inside the dock’s polite live region only for prompt changes; readings themselves are not announced on every packet.

Keyboard

KeyAction
TabThe strip is not focusable; it scrolls by touch, and the same values are in the side panel or evidence log.

Focus

Not focusable.

Labelling

Confidence markers have visually hidden words: “Incline (likely)”.

Contrast

Live ratios, light then dark.

Value
Unit and label
Live label

Motion

The Live dot pulses every --duration-pulse; it stops under reduced motion. Values change in place without animation.

Touch

Not a target.

Content

  • One decimal for speed and incline; whole metres; m:ss for time.
  • Units in SI as the device reports them; never converted silently.

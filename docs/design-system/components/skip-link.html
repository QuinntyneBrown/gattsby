Skip link

Overview

Every mock starts with <a class="skip-link" href="#main">Skip to content</a>. It is off-screen until focused.

Accessibility

Role and pattern

<a href="#main">; <main id="main"> is the target.

Keyboard

KeyAction
TabFirst stop on the page; shows the link.
EnterMoves focus to the main content.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

“Skip to content”.

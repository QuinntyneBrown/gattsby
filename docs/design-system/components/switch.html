Switch

A switch turns a setting on or off at once, such as using the agent when the on-device model is available. It always sits in a setting row with a title and what the setting does.

WCAG 2.2 AAStatus: stable

Overview

Use a switch only in Settings, for a preference that applies immediately and can be turned back. It never confirms a safety step (that is a checkbox) and never starts an action (that is a button).

Anatomy

  1. Group title.section-title.
  2. Setting textTitle and what “off” means.
  3. Switch44 × 24px track inside a 48px target; thumb slides 20px.

Variants

Responsive behaviour

  • The row keeps the switch at the right edge at every width; the text wraps.

Theming

Off is a --color-border-strong track (3:1 against the surface); on is --color-accent. The thumb is --color-bg-surface with --shadow-1.

Accessibility

Role and pattern

<input type="checkbox" role="switch">; the state is announced as on or off.

Keyboard

KeyAction
TabMoves to the switch.
SpaceToggles.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

aria-labelledby points at the setting title; the label names the setting, not the action (“Use the agent”, not “Turn on”).

Content

  • Never “Enable”/“Disable” in the title.

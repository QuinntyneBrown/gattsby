Missing-tool request

A missing-tool request records a capability the agent lacked, such as decrypting a vendor’s packets, with the devices that needed it and whether it has since been built.

WCAG 2.2 AAStatus: stableFR-058

Overview

Listed on the Missing tools page (.req) and summarised on a verdict (tool card). Each has a title naming the capability, a status pill, what was observed and which devices raised it.

Anatomy

  1. TitleThe capability, as a verb phrase.
  2. PillOpen · n devices, or Built.
  3. ObservationWhat the agent saw.
  4. MetaDevices and when first raised.

Responsive behaviour

  • The pill wraps under the title on narrow screens.

Theming

Open uses the signal pair (--color-signal-subtle, --color-fg-signal): a missing tool is a live gap. Built uses success.

Content

  • Title says the capability, not the failure: “Decrypt Kingsmith FE00 packets”.
  • Observation says what was seen and that Gattsby did not try to get around it (AGENTS.md, Respect the store).

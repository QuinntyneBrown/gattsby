Tool call

A tool call shows one step the agent took: which tool ran, why, how long it took, what it found and a link to the raw evidence.

WCAG 2.2 AAStatus: stable

Overview

.probe is a card indented under the agent’s message. Its head shows the tool name in an inverse mono chip (the registry name, TOOL-002 to TOOL-034), its purpose and duration. Its body gives the result in a sentence, then rows or observations with confidence badges, then Evidence.

Anatomy

  1. ToolRegistry name, mono, inverse chip.
  2. PurposeCaption, truncates.
  3. TimeMono.
  4. Result and observationsSentence, then badges.
  5. Evidence linkOpens the raw packets.

Responsive behaviour

  • Indented 32px under the message at every width; the purpose truncates first.

Theming

The tool chip uses --color-bg-inverse; the card is --color-bg-surface; error swaps the edge to --color-danger-border.

Accessibility

Role and pattern

A list item containing a header line, a paragraph and a table or list; rows tables have a visually hidden caption.

Keyboard

KeyAction
TabReaches Evidence.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

The running spinner has role="status" with “Running”.

Contrast

Live ratios, light then dark.

Content

  • Purpose: a verb phrase about the device, not the code (“Listen to 0x2ACD for 10 s”).
  • Result: one sentence of what was found, including refusals: “I won’t try to get around it.”

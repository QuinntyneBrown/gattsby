Code and bytes

Bytes, UUIDs and versions are set in Geist Mono: inline code, the bytes a command will send, and a copy field for the app’s address.

WCAG 2.2 AAStatus: stable

Overview

  • Inline code (code), and keys (kbd).
  • Bytes (.bytes): a label and a mono value on a sunken well; the approval sheet shows what will be sent and the risk.
  • Copy field (.copy-field): a value with a Copy button, on the unsupported-browser screen.

Anatomy

  1. LabelCaption, muted.
  2. Value--text-code-sm, tabular.

Responsive behaviour

  • Byte values wrap at spaces; the copy field truncates its value with an ellipsis.

Theming

Wells use --color-bg-surface-sunken, darker than the surface in ink.

Accessibility

Role and pattern

code, kbd; bytes are text.

Keyboard

KeyAction
TabReaches Copy.
EnterCopies.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

“Copy link”; the result is announced.

Contrast

Live ratios, light then dark.

Motion

None.

Touch

Content

  • Hex in upper case, bytes separated by spaces; UUIDs with 0x.
  • Arrows show direction: ← written to, → read from.

Row list

Row lists show saved devices, past investigations and the readiness checks: one line each, a verdict mark, a title, a meta line and a date.

Overview

.rows is a ruled list; each .row is a link at least 48px tall. Titles and meta truncate on one line, so the list scans quickly on a phone.

Anatomy

  1. Verdict markWith hidden verdict text.
  2. TitleDevice name, 16px medium.
  3. MetaType · protocol.
  4. AsideDate, caption.

Responsive behaviour

  • Single column at every width; the reading page caps the list at 42rem.
  • Meta and title truncate; the aside never does.

Theming

Rules read --color-border-default; hover is a half-strength --color-bg-subtle wash.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind.

Labelling

Link text is the whole row: “Connected: Horizon T202, Treadmill · FTMS · Treadmill, Today”.

Stage track

The stage track shows where the investigation is in the seven-stage playbook: done, now, skipped or to do.

WCAG 2.2 AAStatus: stable

Overview

Seven segments under the app bar: Prepare, Find, Identify, Standard path, Proprietary path, Control, Conclude (FR-049). The path not taken shows as skipped. The current stage is signal orange, taller, and always named in text in the app bar subtitle.

Anatomy

  1. DoneInk segment.
  2. NowSignal, 6px tall, aria-current="step".
  3. SkippedDashed, 60% opacity.

Variants

  1. Prepare: done
  2. Find: done
  3. Identify: done
  4. Standard path: now
  5. Proprietary path: skipped
  6. Control: to do
  7. Conclude: to do
Standard path now; proprietary path skipped.

Responsive behaviour

  • Full width under the app bar; side padding 16px, 24px from 768px.

Theming

Done reads --color-accent, now --color-signal, to-do --color-bg-subtle, skipped a dashed --color-border-strong.

Accessibility

Role and pattern

An ordered list with aria-label="Playbook, stage 4 of 7: Standard path"; each segment has visually hidden text with its status.

Keyboard

KeyAction
—Not focusable; read as a list.

Focus

Not focusable.

Labelling

The list label states the current stage; each item says “done”, “now”, “skipped” or “to do”.

Contrast

Live ratios, light then dark.

Done segment
Current segment (redundant: named in text)

Motion

Segments change colour without animation.

Touch

Not a target.

Content

  • Use the playbook’s stage names only (FR-049).

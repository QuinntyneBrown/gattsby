Card

Cards group one thing: a paused investigation to resume, the missing tool a verdict raised, a labelled well of detail.

WCAG 2.2 AAStatus: stable

Overview

  • Card (.card): surface, hairline edge, --shadow-1, 24px padding.
  • Resume card (.resume-card): an inverse, full-width link on Home that picks up a paused investigation.
  • Tool card (.tool-card): inverse block on a verdict that names the missing-tool request it raised.
  • Well row (.well-row): sunken summary inside a sheet (“Leaving: Horizon T202”).

Anatomy

  1. IconPause, in a 40px circle.
  2. TitleWhat to resume.
  3. MetaWhere it stopped and when.
  4. ChevronIt is a link.

Responsive behaviour

  • Full width at every size; the resume card’s meta truncates with an ellipsis, the title wraps.

Theming

Resume and tool cards use --color-bg-inverse, so they flip with the theme and always stand out from the page.

Accessibility

Role and pattern

A resume card is one <a>; a tool card is a <section aria-labelledby> with a real link inside.

Keyboard

KeyAction
TabReaches the card link.
EnterFollows it.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only, so a tap never leaves a ring behind. Resume cards use a 3px offset so the ring clears the inverse fill.

Labelling

The card text is the link text: “Resume: spin bike, Basic-Fit Roubaix. Paused at Standard path · 2 h ago”.

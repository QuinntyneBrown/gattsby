Dialogs and overlays

Bottom sheets, centred dialogs, stacking, inert pages.

Overview

Every overlay is a sheet: modal, focus-trapped, with the page behind it inert. There are no popovers, tooltips or drawers.

When to use

NeedUse
A decision before going onSheet with two named buttons
A set of actionsSheet with a menu
A destructive confirmationSheet, danger primary, typed confirmation for delete all data
Something to read at lengthA page, not a sheet

Structure

Emergency stop

Investigation options

  • Pause
  • Add a note or the location
  • Photo of the model plate or console
  • Evidence
  • Stop and get a verdict now
Options sheet.

States

StateRule
DefaultFocus on the first input or the title.
BusyPrimary loading; Close still works unless closing would lose a write in flight.
InvalidSummary at the top.
FailedDanger alert inside; sheet stays open.

Responsive behaviour

  • Bottom sheet under 576px; centred from 576px.
  • Never stack two sheets; the second replaces the first.

Accessibility

  • APG modal dialog; Esc closes; focus returns to the trigger.
  • Over a connected device, the stop is in the sheet.

Content

  • Titles are questions or the name of the thing.

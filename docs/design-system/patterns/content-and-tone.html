Overview

See the content foundation for voice, the specs’ words, formats and microcopy. This pattern shows them in context.

When to use

  • Always: every string a person reads.

A prompt: instruction, what will happen, the observed answers.

States

MomentExample
AskingIs there a brand on it?
ExplainingWhy: Chrome only lets a page see a device you choose yourself.
ApprovingLower the target speed to 5.9 km/h?
FailingCouldn’t reconnect after 3 tries. Check the treadmill is on, then try again.
RefusingI didn’t try to get around it.

Responsive behaviour

  • Shorter labels on phones only where the full label stays available to screen readers (Stop / Emergency stop).

Accessibility

  • Plain words; no jargon in prompts; UUIDs and bytes only where the person can compare them.

Content

  • First person for the agent; second person for the person.
  • The specs’ words, never synonyms.

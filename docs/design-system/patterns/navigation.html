Overview

Gattsby is shallow: Home leads to an investigation, its verdict and device profile, saved devices, past investigations, missing tools and settings. There is no sidebar or tab bar; the app bar carries Back and the actions for the current screen, and extra actions live in the options sheet.

States

Leaving a running investigation opens the leave sheet (FR-018); everything found so far is already saved (FR-060).

Responsive behaviour

  • Under 768px Pause moves into the options sheet.
  • Page widths: page 64rem, reading 42rem, narrow 28rem.

Accessibility

  • One <h1> per screen; skip link; Back has a name that says the consequence.

Content

  • Titles are the device or page name, not “Details”.

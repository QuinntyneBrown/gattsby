Investigation layout

Feed, prompt, live readings and panel at each breakpoint.

Overview

The investigation screen composes the app bar, stage track, hypothesis strip, activity feed, prompt dock, live readings and composer. Under 992px it is one column: the feed scrolls, and the dock and composer are pinned at the bottom. From 992px the prompt and live readings sit beside the feed in a 22rem column (NFR-010 AC3).

When to use

  • Only the investigation uses this layout; every other page uses a page column.

Responsive behaviour

  • Breakpoints at 768px (padding) and 992px (two columns).
  • The app shell is 100dvh; only the feed scrolls.

Accessibility

  • Landmarks: header (app bar), main (feed and dock), complementary (side panel).
  • The dock is a polite live region; the feed is a labelled scroll region.
  • DOM order: feed, prompt, composer, panel.

Content

  • The prompt is the only instruction on screen; the feed is history.

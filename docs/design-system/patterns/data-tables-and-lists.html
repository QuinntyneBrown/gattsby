Data tables and lists

Rows, key-value lists, tables, filters and search.

WCAG 2.2 AA
  • Overview

  • States
  • Responsive behaviour
  • Accessibility

Overview

Lists are for things to open (rows); key-value lists for facts about one thing; tables for facts with several attributes each (metrics with rule, rate and status).

When to use

ContentUse
Saved devices, past investigationsRow list with verdict mark
Identity, readingsKey-value list
Metrics and controlsData table
Raw packetsEvidence entries

Structure

  • Connected: Horizon T202Treadmill · FTMS · TreadmillToday
  • Connected: Polar H10Heart-rate strap · Heart RateNov 22
  • Connected: Schwinn IC4Spin bike · FTMS · Indoor BikeNov 19
  • Partially decoded: Concept2 RowErgRower · PM5 proprietary, partly decodedNov 14
Search, filters and rows.

States

StateRule
LoadingSkeleton rows.
EmptyEmpty state.
FilteredChips pressed; count in the heading.
No resultsCompact empty state naming the query.

Responsive behaviour

  • Lists stay one column; tables fit 360px by putting rules under the metric.
  • Chip rows scroll sideways; the page never does.

Accessibility

  • Filter chips in a labelled group with aria-pressed.
  • Tables have captions and scoped headers.

Content

  • Lists are ordered newest first.

# Journeys

In order of value. Effort is days for one intermediate developer, tests included. Journey 2 carries
the shared core (BLE layer, knowledge base, store).

| # | Journey | Description | Effort (days) | % complete |
|---|---|---|---|---|
| 1 | Scaffold the app | Angular workspace, app shell, CI, lint and Playwright with device fakes. | 5 | 100 |
| 2 | Identify a standard machine | Scan, connect and name an FTMS or heart-rate device's protocol. | 10 | 0 |
| 3 | Confirm live metrics | Decode live data and confirm it with a walk or pedal. | 6 | 0 |
| 4 | Export the device profile | Save the verdict and profile as versioned JSON. | 3 | 0 |
| 5 | Check readiness | Show missing browser capabilities, what they limit and how to fix. | 3 | 0 |
| 6 | Investigate with the agent | Gemini Nano chooses each validated step of the playbook. | 12 | 0 |
| 7 | Investigate by checklist | Follow the same playbook step by step without a model. | 4 | 0 |
| 8 | Test one control command | Approve one low-risk command, with emergency stop always available. | 8 | 0 |
| 9 | Pick the right device | Tell several nearby candidates apart before connecting. | 3 | 0 |
| 10 | Recover a dropped connection | Detect a drop, reconnect and carry on the investigation. | 3 | 0 |
| 11 | Pause, stop and resume | Pause or stop an investigation and resume it later. | 3 | 0 |
| 12 | Report a non-connectable device | Explain that a Classic, ANT+, Wi-Fi or USB device is unreachable. | 2 | 0 |
| 13 | Decode a proprietary protocol | Record traffic, find varying fields, guess encodings and framing. | 12 | 0 |
| 14 | Review evidence and missing tools | See the hypothesis, its evidence and capabilities the agent lacked. | 4 | 0 |
| 15 | Browse and delete history | List past investigations and delete one or all. | 3 | 0 |
| 16 | Import profiles and records | Load an exported profile or record back into the app. | 3 | 0 |
| 17 | Work offline | Run fully offline once loaded, with no network requests. | 3 | 0 |
| 18 | Unlock vendor data safely | Send a known vendor unlock, never bypassing encryption or pairing. | 4 | 0 |
| 19 | Read a model plate photo | Photograph the model plate to identify maker and model. | 5 | 0 |
| 20 | Use the agent on a phone | Run full agent mode once phones offer an on-device model. | 5 | 0 |
